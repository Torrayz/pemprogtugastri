# TRI PUJI — Academic Portfolio

A modern, mobile-friendly personal academic portfolio rebuilt from an early HTML hyperlink exercise.

## Pages
- `index.html` and `home.html`: landing and featured areas.
- `profil.html`: personal academic background.
- `about.html`: origin and purpose of the website.
- `galery.html`: clearly marked exploration categories.
- `kontak.html`: GitHub contact.

## Design
Deep navy, aqua accent, Manrope + DM Sans, responsive layouts, purposeful hover effects, reduced-motion support, and cohesive navigation.

## Run and deploy
Static HTML and CSS only; no database or build command required. Open `index.html` with a local static server, or host using GitHub Pages / Vercel static deployment.

## Privacy
No private email, phone or address is published. Academic project descriptions are not presented as verified professional experience.
